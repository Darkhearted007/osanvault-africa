# ÒsánVault Africa - Bug Bounty Program

## Overview

We value the security community's help in identifying vulnerabilities in our platform. This program outlines how to report security issues and our reward structure.

---

## Scope

### In Scope
- Smart Contracts (programs/*.rs)
- Backend API (apps/api/src/)
- Frontend Web App (apps/web/src/)
- Integration vulnerabilities

### Out of Scope
- Social engineering
- Physical security
- DDoS attacks
- Third-party services

---

## Vulnerabilities We Care About

### Critical ($5,000 - $50,000)
- Smart contract re-entrancy
- Access control bypass
- Fund theft or freezing
- Token minting vulnerability
- Oracle manipulation

### High ($1,000 - $5,000)
- SQL injection
- Authentication bypass
- Privilege escalation
- Data leakage

### Medium ($250 - $1,000)
- XSS vulnerabilities
- CSRF attacks
- Information disclosure
- Insecure direct object references

### Low ($50 - $250)
- Minor UX issues
- Non-sensitive data exposure
- Documentation errors

---

## Rules

### Do
- Report responsibly
- Allow time to fix before disclosure
- Provide detailed reproduction steps
- Test on testnet/devnet first

### Don't
- Attack mainnet
- Access other users' funds
- Share findings publicly until fixed
- Social engineering the team

---

## How to Report

### Email
```
To: Olugbenga1000@gmail.com
Subject: [SECURITY] ÒsánVault Bug Bounty

Include:
- Description of vulnerability
- Impact assessment
- Steps to reproduce
- Proof of concept (if possible)
- Suggested fix (optional)
```

### Response Time
- **Initial Response:** 24 hours
- **Severity Assessment:** 3 days
- **Fix Timeline:** Based on severity
